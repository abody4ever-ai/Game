# Lido / ليدو
لعبة لودو عربية RTL مبنية بـ Flutter، أوفلاين وبدون إعلانات.

## ما تم تطويره
- شاشة بداية واختيار نمط اللعب.
- 2–4 لاعبين.
- ضد الكمبيوتر بثلاثة مستويات أو لاعبان على نفس الجهاز.
- تجميع الرميات: كل 6 تولد رمية إضافية، وبعدها تظهر كل الأرقام المتاحة للاختيار.
- الخروج من البيت بالـ6، والأكل، والمربعات الآمنة، والدخول بالعدد الدقيق.
- السد: حجران من اللون نفسه في المربع، ويتحرك السد كاملًا عند اختيار عدد زوجي.
- السد يعبر السد، والحجر الفردي لا يعبر سدًا.
- السد في منطقة آمنة لا يمنع المرور.
- واجهة خشبية RTL.

## إخراج APK
على جهاز عليه Flutter وAndroid SDK:

```bash
flutter pub get
flutter build apk --release
```

الناتج عادة في `build/app/outputs/flutter-apk/app-release.apk`.
